# CRM验证材料与适用范围

本轮为求职材料整理，只读查看历史项目文件，没有运行业务系统、重跑测试或修改客户数据。

| 材料 | 可以说明什么 | 不能说明什么 |
| --- | --- | --- |
| 本人实际使用确认 | 网页CRM用于个人拓客和跟进，一笔咨询项目签单 | 不证明签单全部由工具带来或软件被客户购买 |
| 需求与版本记录 | 业务范围、迭代判断和实现过程有文档 | 不表示文档中所有规划已完成 |
| 商机流程测试代码 | 设计了来源、重复处理等检查点 | 本轮没有重跑，不称当前全部通过 |
| 手动商机资料编辑历史日志 | 在隔离临时库验证资料编辑、阶段保护等 | 不代表公海、全部M1或生产系统已验收 |
| 当前状态文档 | 开发与部署阶段有记录，待验事项可追踪 | 不代替本轮现场登录、业务读回和部署验证 |
