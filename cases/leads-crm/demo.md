# CRM五分钟演示提纲

本文件为面试演示准备，不是本轮已录制的视频。正式演示使用已确认可运行版本和合成数据；不能访问真实系统时，用案例与流程图讲解并说明限制。

| 时间 | 展示内容 | 要说明的判断 |
| --- | --- | --- |
| 0:00—0:40 | 业务背景与职责 | 为什么需要持续管理商机；本人主导与AI实现的分工 |
| 0:40—1:30 | 一条线索的来源及信息 | 什么是可信来源，为什么值得或不值得跟进 |
| 1:30—2:30 | 客户、商机和跟进记录 | 三类信息如何关联，实际操作怎样回写结果 |
| 2:30—3:30 | 公海与历史保留 | 管理变化后为何仍保留原跟进状态及历史 |
| 3:30—4:20 | 一项反馈形成的迭代 | 从发现问题到需求、测试和版本记录的过程 |
| 4:20—5:00 | 使用结果与限制 | 咨询签单与工具的关系；当前技术依赖与待验能力 |

## 需要准备的可展示证据

1. 脱敏系统总览，能辨认版本与环境。
2. 一条合成商机的来源、客户及跟进页面。
3. 公海前后的原跟进状态与历史对照。
4. 一项需求到验证的对应材料。
