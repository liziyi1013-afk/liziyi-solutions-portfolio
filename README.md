## 我的工作方式

1. 从业务人员的实际操作出发，识别需求中的遗漏、冲突和异常情况。
2. 用原型、流程和规则说明对齐客户与研发，确认本次实施范围。
3. 参与测试与验收，跟踪问题和使用反馈，形成后续改进任务。
